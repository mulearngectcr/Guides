## 🛠️ Step 1: Implement the Calculator Function

The calculator function will evaluate mathematical expressions.

```python
def calculator(expression: str) -> float:
    """
    Performs mathematical calculations on a given expression.

    Args:
        expression (str): A mathematical expression (e.g., "2500 * 0.18")

    Returns:
        float: The result of the calculation

    Raises:
        ValueError: If the expression is invalid
    """

    # List of allowed characters (prevent security issues)
    allowed_chars = set('0123456789+-*/.() ')

    # Check if expression contains only allowed characters
    if not all(char in allowed_chars for char in expression):
        raise ValueError(
            f"Invalid characters in expression: {expression}. "
            "Only numbers, operators (+, -, *, /), and parentheses allowed."
        )

    try:
        # Evaluate the expression safely
        result = eval(expression)
        return result
    except ZeroDivisionError:
        raise ValueError("Cannot divide by zero")
    except Exception as e:
        raise ValueError(f"Error evaluating expression: {str(e)}")

# Test it locally
print(calculator("2500 * 0.18"))  # Should print 450.0
print(calculator("10 + 5 * 2"))   # Should print 20.0
print(calculator("100 / 4"))      # Should print 25.0
```

**Understanding the function:**

1. **Input**: Takes a mathematical expression as a string
2. **Validation**: Checks that only safe characters are used (prevents code injection)
3. **Evaluation**: Uses Python's `eval()` to calculate the result
4. **Error Handling**: Catches division by zero and other errors
5. **Output**: Returns the numerical result

### Why This Validation?

The `eval()` function is powerful but dangerous. Without validation, someone could run malicious code:

```python
# ❌ DANGEROUS - Don't do this
eval("__import__('os').system('rm -rf /')")  # Delete everything!

# ✅ SAFE - With validation
calculator("__import__('os').system('...')")  # Blocked by validation
```

## 🛠️ Step 2: Define the Tool for the LLM

Now the LLM needs to know about your calculator. Create a tool definition:

```python
# This is what we tell the LLM about our calculator
calculator_tool = {
    "type": "function",
    "function": {
        "name": "calculator",
        "description": (
            "A mathematical calculator tool that evaluates mathematical "
            "expressions. Use this tool to perform calculations like adding, "
            "subtracting, multiplying, dividing, and working with percentages. "
            "Supports operators: +, -, *, /, and parentheses for grouping."
        ),
        "parameters": {
            "type": "object",
            "properties": {
                "expression": {
                    "type": "string",
                    "description": (
                        "A mathematical expression to evaluate. "
                        "Examples: '2500 * 0.18', '(10 + 5) * 2', '100 / 4'. "
                        "Do not include the word 'calculate' or other text, "
                        "only the mathematical expression."
                    )
                }
            },
            "required": ["expression"]
        }
    }
}
```

**What each part means:**

- `type`: "function" (indicates this is a callable tool)
- `name`: The exact name the LLM will use: "calculator"
- `description`: Clear explanation of what the tool does and when to use it
- `parameters`: Describes the input (in this case, just the expression)

## 🛠️ Step 3: Set Up API Connection

Create a function to communicate with your LLM provider:

```python
import os
import json
import requests
from dotenv import load_dotenv

# Load API key from environment
load_dotenv()
GROQ_API_KEY = os.getenv("GROQ_API_KEY")

def call_llm(messages, tools=None):
    """
    Sends messages to the LLM and gets a response.

    Args:
        messages: List of message dicts with 'role' and 'content'
        tools: List of available tools (optional)

    Returns:
        dict: The LLM's response
    """

    # Prepare the API request
    url = "https://api.groq.com/openai/v1/chat/completions"

    headers = {
        "Authorization": f"Bearer {GROQ_API_KEY}",
        "Content-Type": "application/json"
    }

    payload = {
        "model": "mixtral-8x7b-32768",  # Groq's fast model
        "messages": messages,
        "temperature": 0.7,
    }

    # Include tools if provided
    if tools:
        payload["tools"] = tools
        payload["tool_choice"] = "auto"  # Let LLM decide whether to use tools

    # Make the API request
    response = requests.post(url, headers=headers, json=payload)

    # Handle errors
    if response.status_code != 200:
        print(f"Error: {response.status_code}")
        print(f"Response: {response.text}")
        return None

    return response.json()

# Test the connection
test_messages = [
    {
        "role": "user",
        "content": "Say hello"
    }
]

response = call_llm(test_messages)
print(response["choices"][0]["message"]["content"])  # Should say hello
```

**What this function does:**

1. Takes your messages and sends them to Groq's API
2. Includes tool definitions so the LLM knows about your calculator
3. Lets the LLM decide whether to use tools automatically
4. Returns the LLM's response

## 🛠️ Step 4: Create the Function Calling Loop

This is where everything comes together:

```python
def process_tool_call(tool_name, tool_args):
    """
    Executes a tool based on its name and arguments.

    Args:
        tool_name (str): Name of the tool to execute
        tool_args (dict): Arguments for the tool

    Returns:
        str: Result of the tool execution
    """

    if tool_name == "calculator":
        try:
            result = calculator(tool_args["expression"])
            return str(result)
        except ValueError as e:
            return f"Error: {str(e)}"
    else:
        return f"Unknown tool: {tool_name}"


def chat_with_calculator(user_input):
    """
    Main function for chatting with the LLM using the calculator tool.

    Args:
        user_input (str): The user's question or statement

    Returns:
        str: The LLM's final response
    """

    # Start conversation with user's message
    messages = [
        {
            "role": "user",
            "content": user_input
        }
    ]

    print(f"\n👤 You: {user_input}\n")

    # Keep calling the LLM until it gives a final response (no tool calls)
    max_iterations = 5  # Prevent infinite loops
    iteration = 0

    while iteration < max_iterations:
        iteration += 1

        # Call the LLM with available tools
        response = call_llm(messages, tools=[calculator_tool])

        # Get the response message
        message = response["choices"][0]["message"]

        # Add assistant's response to conversation
        messages.append({
            "role": "assistant",
            "content": message.get("content", ""),
            "tool_calls": message.get("tool_calls")
        })

        # Check if LLM wants to use tools
        tool_calls = message.get("tool_calls")

        if not tool_calls:
            # No tool calls - LLM is done, return final response
            final_response = message.get("content", "")
            print(f"🤖 Bot: {final_response}\n")
            return final_response

        # Process each tool call
        print(f"🛠️  Tool called: {tool_calls[0]['function']['name']}")

        for tool_call in tool_calls:
            tool_name = tool_call["function"]["name"]
            tool_args = json.loads(tool_call["function"]["arguments"])

            print(f"   📊 Expression: {tool_args.get('expression', 'N/A')}")

            # Execute the tool
            result = process_tool_call(tool_name, tool_args)

            print(f"   ✓ Result: {result}\n")

            # Add tool result to conversation
            messages.append({
                "role": "tool",
                "tool_call_id": tool_call["id"],
                "name": tool_name,
                "content": result
            })

    return "Max iterations reached without a final response"
```

**What this does step by step:**

1. **Initialize**: Start with the user's question
2. **Loop**: Keep communicating with the LLM until it doesn't call tools
3. **Check for tools**: Look if LLM wants to call a tool
4. **Execute tool**: If yes, run the calculator function
5. **Send result back**: Add the result to the conversation
6. **Repeat**: Send everything back to LLM for final response
7. **Exit**: When LLM doesn't call tools anymore, return the final response

## 🐛 Troubleshooting

### Error: "Unable to retrieve kwargs from tool"

**Cause**: Tool arguments format is wrong
**Fix**: Make sure arguments are properly serialized as JSON

### Error: "Division by zero"

**Cause**: Expression contains `/0`
**Fix**: Your error handling catches this - it should show a friendly message

### Error: "Invalid characters in expression"

**Cause**: Expression contains characters outside allowed set
**Fix**: This is security working as intended. Only use numbers and operators.

### Error: "API key not found"

**Cause**: `.env` file not loaded correctly
**Fix**: Ensure `.env` file exists in the same directory and `load_dotenv()` is called
