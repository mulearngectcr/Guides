# Part 1: Understanding Function Calling

> Your first step into AI tools

---

## 📖 Introduction

Think about how you use a calculator in real life.

When you need to calculate something complex—like finding what 18% of 2500 is—you don't do the math in your head. You **use a tool** (a calculator) to get the answer.

Large Language Models (LLMs) work similarly.

**LLMs are very smart at understanding language and reasoning, but they're not designed to perform precise mathematical calculations or access real-time information.**

When an LLM needs to:

- Perform calculations
- Look up current weather
- Query a database
- Check an API
- Access external services

...it needs to **call a function** (use a tool).

This is called **function calling**.

---

## 🤔 What is Function Calling?

Function calling is a technique that allows LLMs to request specific actions from your code instead of just generating text responses.

### Without Function Calling

```
You: What is 18% of 2500?

LLM: Based on mathematical principles, 18% of 2500 can be
calculated by multiplying 2500 by 0.18, which equals 450.
```

The LLM tries to solve it using reasoning alone. It might work, but it could also make mistakes.

### With Function Calling

```
You: What is 18% of 2500?

LLM: I need to calculate this. Let me use the calculator tool.

🛠️  Tool Call: calculator(expression="2500 * 0.18")

Your Code Executes: 2500 * 0.18 = 450

LLM: The result is 450. So 18% of 2500 is 450.
```

The LLM asks your code to do the calculation, then uses the result in its response.

---

## 🎯 Why Do LLMs Need Function Calling?

### Reason 1: Accuracy

LLMs can make mathematical errors. A calculator never does (for supported operations).

**Example:**

```
Prompt: Calculate 127 × 456

LLM (without tools): 127 × 456 = 57,912
Actual answer: 57,912 ✓ (Got lucky!)

But with complex calculations, errors happen:
Prompt: What is 789 × 0.123?
LLM: Approximately 97
Actual answer: 97.047 (Close, but not exact)
```

### Reason 2: Real-Time Information

LLMs have a knowledge cutoff. They don't know today's date or current weather.

**Example:**

```
Prompt: What's the weather in New York right now?

LLM (without tools): I don't have access to real-time data.

LLM (with tools): Let me check the weather API.
🛠️  Tool Call: get_weather(city="New York")
Result: Sunny, 72°F

LLM: It's currently sunny in New York with a temperature of 72°F.
```

### Reason 3: External Data Access

LLMs can't access databases, files, or web services directly.

**Example:**

```
Prompt: How many users have signed up today?

LLM (without tools): I can't access your database.

LLM (with tools): Let me query your database.
🛠️  Tool Call: get_signup_count(date="today")
Result: 47

LLM: 47 users have signed up today.
```

### Reason 4: Complex Operations

Sometimes you need to guarantee that specific logic runs correctly.

**Example:**

```
Bank Account Transfer:
Prompt: Transfer $100 from Account A to Account B

LLM (without tools): Cannot guarantee correctness

LLM (with tools): Let me execute a transfer operation.
🛠️  Tool Call: transfer_money(from_account="A", to_account="B", amount=100)
Result: Success, new balance in A: $900

LLM: Transfer complete!
```

## 🌍 Real-World Examples of Function Calling

### Example 1: Chat with Code Search

**ChatGPT's Code Interpreter**

```
User: Analyze this dataset and create a visualization

LLM: I need to use Python to analyze the data.
🛠️  Tool Call: execute_python_code(code="...")
Result: [visualization data]

LLM: Here's your visualization...
```

### Example 2: AI Assistants

**Microsoft Copilot using Bing Search**

```
User: What are the latest AI breakthroughs in 2024?

LLM: I need current information.
🛠️  Tool Call: bing_search(query="AI breakthroughs 2024")
Result: [Recent articles]

LLM: Based on recent news, here are the latest breakthroughs...
```

### Example 3: Calendar Assistant

**Scheduling an appointment**

```
User: Schedule a meeting with John tomorrow at 2 PM

LLM: I need to access your calendar.
🛠️  Tool Call: create_calendar_event(
  title="Meeting with John",
  time="2024-09-03 14:00"
)
Result: Event created, ID: 12345

LLM: I've scheduled your meeting with John tomorrow at 2 PM.
```

## 🔧 Key Concepts

### The Tool

A tool is a function that performs a specific action. In our calculator example:

```python
def calculator(expression: str) -> float:
    """
    Performs mathematical calculations.

    Args:
        expression: A mathematical expression like "2500 * 0.18"

    Returns:
        The result of the calculation
    """
    return eval(expression)  # Simplified example
```

### The Tool Definition

LLMs don't know about your function unless you describe it. You must provide a **tool definition** that tells the LLM:

- What the tool does
- What parameters it needs
- What type of response it gives

```python
{
    "name": "calculator",
    "description": "Performs mathematical calculations",
    "parameters": {
        "type": "object",
        "properties": {
            "expression": {
                "type": "string",
                "description": "A mathematical expression (e.g., '2500 * 0.18')"
            }
        },
        "required": ["expression"]
    }
}
```

### The Function Calling Loop

Here's the process:

1. **User asks a question** → LLM processes it
2. **LLM decides** → Does it need tools?
3. **If yes** → LLM generates a tool call (function name + parameters)
4. **Your code executes** → Runs the function with those parameters
5. **Send result back** → LLM receives the result
6. **LLM generates response** → Creates final answer for user

---

## 📌 Key Takeaways

- **Function calling** lets LLMs use external tools
- LLMs decide **when** to use tools based on the user's question
- Tools provide **accuracy**, **real-time data**, and **external access**
- A tool needs:
  - Implementation (the actual function)
  - Definition (description of what it does)
  - Parameters (what inputs it needs)
